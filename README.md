# Tipperary Equestrian Centre website demo

Development concept for review by the Ryan family.

- `index.html` — main demo site
- `proposal.html` — temporary client note and international reference links
- `privacy.html` — demo privacy/cookie note
- `styles.css` / `app.js` — site styles and behaviour
- `assets/` — supplied and concept imagery

The demo availability and enquiry form are intentionally non-functional. Temporary development/reference material should be removed before an official launch.
